Status: **Implemented and verified locally.** Extends the Phase 19/44/45/46 image engine in place (`server/imageEditor/`); no duplicate filter path — the Phase 19 adjustments are wrapped by the registry, not reimplemented. Acceptance is the owner's decision.

## What was built

All in the existing engine — `types.ts` (model) and `imageCore.ts` (operations). Every filter is a pure function `PixelImage -> PixelImage` behind one registry; nothing is exposed that is not implemented and tested below.

- **Registry / uniform API** — `FilterDescriptor` (id, display name, parameter schema: name, min, max, default) and `listFilters()` / `getFilterDescriptor(id)` returning defensive copies, so a UI can render controls from data. Entry points: `applyFilterToImage(img, id, params)` (pure), `applyFilter(project, layerId, id, params, options)` (in place, scoped), `previewFilter(...)` and `previewFilterRegion(...)` (same math, project untouched). `resolveFilterParams` validates: unknown filter id, unknown parameter name, non-finite value and out-of-range value all throw; omitted parameters take schema defaults. Nothing is silently clamped.
- **Spatial filters** — box blur (radius; separable, edge-replicating, all four channels convolved, float intermediate rounded once); Gaussian blur (sigma, kernel `exp(-i²/2σ²)` normalized, kernel half-width `ceil(3σ)` unless an explicit `radius` truncates it; all four channels); sharpen (the `[[0,-a,0],[-a,1+4a,-a],[0,-a,0]]` kernel on RGB, alpha preserved); noise (per-channel uniform noise in ±amount driven by mulberry32 seeded by the `seed` parameter — same seed, byte-identical output; alpha preserved); edge detection (Sobel on Rec.601 luminance, magnitude scaled by `strength`, responses below `threshold` suppressed, grayscale output, alpha preserved); emboss (directional luminance derivative along `angle`, output `128 + strength·(gx·cos + gy·sin)`, so a flat image is exactly mid-gray; alpha preserved).
- **Distortions** — wave (vertical displacement `amplitude · sin(2πx/wavelength + phase)`, inverse-mapped bilinear resampling, the Phase 45 warp convention) and swirl (rotation about the canvas centre falling off as `(1 − r/R)²`, full `angle` at the centre and identity at/beyond `radius` — 0 = auto, half the smaller dimension; positive angles follow the engine's existing rotation convention). Both resample all four channels. Only these two distortions are shipped, because only these two are implemented.
- **Color effects** — brightness/contrast, saturation, invert and grayscale are the Phase 19 adjustments themselves, wrapped through a throwaway project so the registry reuses their exact math (byte-equality is tested, not assumed). New: hue-rotate (true HSL hue rotation — pure red +120° is exactly pure green), sepia (the standard matrix, blended by `amount`), posterize (quantize to `levels` evenly spaced values), threshold (Rec.601 luminance against `level`). Point color effects preserve alpha, like the Phase 19 adjustments.
- **Previews** — `previewFilter` returns the would-be layer image as a new `PixelImage`; the project's bytes are untouched (tested byte-for-byte). `previewFilterRegion` returns the filtered crop of a region, computed with the full layer as context so neighborhood filters are correct at region edges; invalid regions throw.
- **Scoping and the existing model** — `applyFilter` computes the filtered layer in full, then blends per pixel by the scope weight: 0/1 for the Phase 19 rect, value/255 for the Phase 45 raster selection (they combine multiplicatively). Because the blend happens after a full-image filter pass, feathered selection edges cross-fade smoothly and neighborhood filters see the true neighborhood at scope boundaries. A layer's Phase 44 mask is neither baked in nor altered — it keeps modulating compositing as before (tested: mask bytes identical after filtering). Like the Phase 19 adjustments, filters ignore the alpha lock, which constrains paint tools.

## Limitations (stated honestly)

- **Only two distortions exist** (wave, swirl). Bulge/pinch and others named in filter wish-lists are not implemented and therefore not in the registry — the registry never advertises an unimplemented effect.
- **Blur edge handling is edge-replication** (clamp), not mirror/wrap; sharpen is a fixed 3×3 kernel (amount scales it, there is no radius control); noise is uniform per-channel noise (no Gaussian or monochrome mode); edge detection is Sobel only.
- **Filters ignore the alpha lock and do not bake the layer mask** — they follow the Phase 19 adjustments' contract: the lock constrains paint tools, and the mask stays a live compositing control. Filters that must respect a mask today can be scoped by converting the mask to a selection (`selectionFromLayerAlpha`) and passing it as `selectionMask`.
- **Gaussian `radius` default of 0 means "auto"** (kernel half-width `ceil(3σ)`); that sentinel is documented in the schema's code comment and progress doc, since the descriptor schema carries numbers only.
- **No filter pipeline/history integration**: filters apply destructively to layer pixels like the Phase 19 adjustments (undo snapshots cover recovery); there is no non-destructive filter stack in this phase.
- **The generated C# desktop editor app** (`imageProjectGenerator.ts`, Phase 19) does not yet expose Phase 47 features — as with Phases 44/45/46, this phase covers the TypeScript engine.
