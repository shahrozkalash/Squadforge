## Known limitations

The generated GUI was never run, clicked, or visually verified (no display on this VM; WinForms does not execute on Linux .NET 8) — compile + PE verification only; runtime and workflow testing is Phase 57. Layer groups are not in the generated app (TS engine only; the app's layer model is flat). Custom raster brush tips are not carried — the Speckle Tip preset is emitted with scalar settings only and paints with the round profile. Selections are rectangle-only (no wand/lasso/feather), with hard in/out scoping. Brush pressure is modelled input data — the mouse reports none, so strokes run at full pressure; smoothing is preset-driven (no dedicated options-bar control). Undo remains the Phase 19 flattened-snapshot mechanism; blend/mask/stack changes are not individually undoable. Not exposed in the app: PSD import/export (Phase 49), 16-bit/grayscale representations and ICC carriage (Phase 50), acceleration providers (Phase 51), actions/batch (Phase 53), guides/grid rendering or snapping (Phase 54 data carried as before; the layout's filters/history/properties panels still render no controls — filters are exposed via the Filters menu instead). Adjustment layers' blend mode/clipped/alpha lock have no effect and content-layer effect stacks cannot be baked, both mirroring the TS engine's documented Phase 52 semantics. Full detail in `PHASE_56_PROGRESS.md`.
