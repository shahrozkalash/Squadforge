## Known limitations

Fonts: only the two built-in bitmap typefaces (`pixel`, `pixel-bold` — the bold set is materialized by a documented 1px dilation of the regular set, not hand-drawn), one 5×7 grid, hard bitmap edges with no anti-aliasing, font sizes snapped to integer scales of the grid, lowercase folded to uppercase, and the documented character set only (everything else renders the fallback box). Layout: no wrapping, justification, per-character styling or text-on-path; outline width and shadow blur/offsets are whole-pixel at render. Canvas-wide operations (crop/resize/step-rotate) act on content layers' render caches, not their data — a later content edit re-renders from data and discards the op's effect on that layer (the Phase 45 transforms compose into placement and do not have this issue). Painting tools paint a content layer's cache, likewise discarded on re-render. Shapes: one shape per layer; path continuity is expected, not enforced; ellipse stroke is a dot-path polyline (fills are exact, width-1 ellipse strokes can be sparse at diagonal extremes); no gradients, dashes or boolean shape operations. The generated C# desktop app does not yet expose Phase 48 features. Full detail in `PHASE_48_PROGRESS.md`.
