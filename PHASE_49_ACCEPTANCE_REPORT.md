## Known limitations

Supported: PSD version 1, RGB color mode, 8-bit depth; layers with bounds/names (Pascal + Unicode)/opacity/visibility/clipping/alpha-lock/six blend modes; groups via section dividers; layer masks (-2/-3 channels with their rectangles); RAW/RLE/ZIP/ZIP-prediction channel compression; flattened files via the merged section (RAW/RLE). Rejected with named errors: PSB files, non-RGB color modes, 16/32-bit depths. Reported in `warnings` and dropped: layer effects, adjustment data, fill-layer data, smart objects, vector data, text editability (`TySh` imports as raster pixels), spot/extra channels, unknown blend keys (imported as `normal`), fill opacity, disabled-mask state (imported enabled), group pass-through semantics (groups always isolate here), and layer content outside the canvas. Export losses: Phase 48 content layers export as rendered pixels and re-import as raster; a fully transparent border around a layer is not preserved as geometry (the data bounding box is stored; all pixels inside it, including transparent ones carrying RGB, are exact); opacity quantizes to 1/255 (a format property). Image resources (ICC profile, resolution, thumbnails) are skipped on import and written empty. The HTTP routes and the generated C# desktop app do not expose PSD in this phase. Full detail in `PHASE_49_PROGRESS.md`.
